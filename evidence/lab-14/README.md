# Lab 14 submission

Start with [Lab_14.md](Lab_14.md) for the answers, assumptions, sources, and completion checklist.

Run from this folder with Python 3 (no packages needed):

```bash
python3 portfolio.py
python3 mandate.py
python3 validate.py
```

Visible executed output is in [outputs/portfolio_run.txt](outputs/portfolio_run.txt), [outputs/mandate_run.txt](outputs/mandate_run.txt), and [outputs/validation_run.txt](outputs/validation_run.txt).

`prices.csv` holds five years of monthly adjusted closes. `download_prices.py` and the raw Yahoo JSON under `data/` document its provenance. Personal reflections and the discussion preparation are drafts for review. Partner participation and GitHub upload/checkout remain personal submission steps.
